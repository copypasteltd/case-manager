# Synthetic PDF/image inputs

These seven small fixtures contain synthetic CP128 review text and printed image text. They are test inputs for actual native embedded-text extraction, mixed/scanned PDF OCR, PNG/JPEG OCR, page-limit rejection, encryption and malformed-input rejection. They contain no company records or real credentials.

The raster fixture was drawn with the review host’s installed Microsoft YaHei font; only image pixels are distributed. Native extraction uses pinned independent Poppler/Tesseract tools and official model data, recorded separately. Passing these fixtures does not establish arbitrary-document accuracy, original PDF layout, handwritten text, production Linux or live cloud acceptance.
