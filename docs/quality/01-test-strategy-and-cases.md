# 测试策略、场景与证据规范

版本：v1.0-draft；日期：2026-10-23。以下为完整首发测试计划，不能把部分分支验证视为整条用例通过。新增原生数据库、接口、Web测试和截图见[实施台账](../delivery/02-implementation-ledger.md)；云、真机、完整业务及恢复验收仍待执行。

## 1. 测试层级与环境

领域测试覆盖状态转移、金额/舍入、账期、依赖环、计划哈希和幂等；PG集成测试覆盖真实事务/唯一约束/锁/撤权；接口测试覆盖Schema、身份/组织/ACL及并发；真实云测试覆盖multipart/摘要/恢复；各端E2E覆盖关键旅程；恢复演练覆盖DB与对象一致性。模型文本质量由固定样本评估，与工具/权限确定性测试分开。

原生Go/Node/Python/PG测试环境、云测试桶/数据库/测试Bot、微信与抖音真机、Android真机；禁止本地Docker/WSL/虚拟机/硬件模拟器。不同环境严格隔离。测试源文件有使用权限，大文件不默认发给模型；恢复测试默认停用所有站外通知。

数据集至少：3个不同权限账号、跨项目受限账号、无内容权限系统管理员、停用账号、两平台身份、两个群披露范围、有效/失效会话；有跨币种/月底/闰年/重复来源/冲销费用；文本/PDF/Office/票据/恶意附件及真实120GB样本。对象数量/版本数/正文量从2TB盘点补齐，不能只用一个120GB文件代表检索规模。

## 3. 性能与容量验证

固定环境、数据量、请求混合、并发与测试时长，3人基线和10人余量分别记录。普通API/搜索分开算p50/p95/p99/错误率；香港不同链路记录端到端耗时；AI首字/最终时延不混入普通接口指标。大文件记录实际吞吐、峰值RSS/临时盘、重传字节、校验/复制耗时和账单样本。

故障注入包括请求超时但DB已提交、租约过期双Worker、云凭证失效、R2限流、PG短断、磁盘配额、模型服务不可用。优先验证数据正确性与恢复，再扩压；不以更高吞吐换越权或丢账。
