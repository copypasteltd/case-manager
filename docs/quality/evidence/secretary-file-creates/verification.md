## 实际覆盖

- 新建目标与原文件更新互斥；文件名、格式、目录版本、同项目／分类、原始受众及当前AI许可受约束。
- 1至48 KiB UTF-8、BOM、一致LF／CRLF和Unicode摘要／预览；空内容、无效编码、NUL、裸CR及混合换行拒绝。
- 真实MCP／控制HTTP通过暂存、准确计划、独立扫描／提升到首版本提交，预备阶段及无扫描状态不能冒充完成。
- 单运行最多3份独立草稿；同名文件／目录冲突不覆盖，目录／祖先版本变化或I/O中撤权阻止继续。
- 正式文件、首版本、审计／Outbox、业务幂等记录及工具凭证整体事务；凭证失败全部回滚，重复提交只返回原结果。
- 消息固定创建来源及摘要，意图／草稿／计划／提交不可改写；目录改名后仍可按当前权限读取已完成历史。
- 两端实际显示从空正文创建的内容、真实首版本及待校验的第二副本；选择不自动发送，取消排队运行不产生正式新文件。
