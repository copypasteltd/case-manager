## 1. 产品目标

把项目、文件、合同与费用、知识、服务状态和秘书放在同一内部工作入口。员工既能通过表单/看板直接工作，也能把有边界的任务交给秘书；两种入口共享权限、状态与证据。项目是聚合视图，不能把所有数据强制复制进某个项目目录。

| PRD-01 | 3 名员工可用不同角色完成登录、项目、文件、申请、知识与状态工作，数据互不越权 | U-04/05/14 |
| PRD-02 | 全部首发平台访问相同业务事实；各端能力分工明确，关键状态不因平台不同而改变 | U-06/18/19 |

| PRD-04 | 指定股东群可通过已绑定身份与秘书沟通，群披露范围受控 | U-10 |

业务改善指标包括找资料耗时、申请周转、未闭环项目比例、资料完整率、重复录入次数、秘书可验证完成率、复制积压和故障发现时间。先测现状再定改善幅度，不编造百分比收益。

## 2. 信息架构与主要入口

Web 顶层入口：工作台、项目、文件、知识、OA、费用与订阅、秘书、服务状态、管理。移动端顶层为工作台、项目、待办、秘书、我的；其他模块从项目或工作台进入。页面与逐端清单见 [客户端规范](../development/06-clients-and-pages.md)。

工作台包含“待我审批、我的任务、即将到期、复制异常、服务事件、秘书待处理”；每个数字按当前人范围计算。管理权限与业务内容阅读分开。首次配置未完成显示缺项和负责人，不伪造空成功状态。

| 旅程 | 起点 → 核心步骤 → 结束 | 异常与结果证据 |
| --- | --- | --- |
| J-01 入用 | 管理员邀请 → 一次性激活 → 设置认证 → 分配角色/项目 | 无公开注册；邀请过期可重发；首次激活有审计 |
| J-02 建项目 | 表单/秘书 → 范围与成员 → 模板预览 → 创建 → 任务/目录初始化 | 必填/权限失败不创建；异步文件失败显示初始化待处理；项目 ID |
| J-03 推进项目 | 分配任务 → 依赖/风险 → 日志 → 里程碑 → 交付验收 | 并发更新冲突、依赖成环、验收退回均有明确状态 |
| J-04 大文件 | 选源 → 预检 → 分片 → 断点恢复 → 检验 → 正式版本 → 副本校验 | 刷新/重启只补缺片；进度区分上传与备份；版本/摘要证据 |
| J-05 文件修改 | 阅读授权版本 → 草稿/差异 → 校验 → 提交新版本 | 基础版变化返回冲突，草稿保留；不覆盖他人更新 |
| J-06 OA | 草稿 → 校验 → 提交修订 → 审批 → 退回重提或通过 → 后续处理 | 通过不等于付款；撤回按流程校验；全流程时间线 |
| J-07 月开支 | 订阅生成预测 → 人工核实实际 → 关联费用/付款 → 汇总 | 未折算币种与未确认数据单列；同笔支出不重复 |
| J-08 股东群 | 提及 Bot → 身份/群校验 → 受理 → 查询/执行 → 摘要+链接 | 未绑定、群无权限、严格受限只给登录入口 |
| J-09 故障 | 外部失败 → 连续确认 → 事件/告警 → 人工处置 → 恢复 → 复盘 | 主应用宕机外部告警仍可达；采集过期为 unknown |
| J-10 归档/恢复 | 检查任务/验收/合同费用 → 归档 → 只读 → 授权恢复/更正 | 不隐式停订阅；不删除原件；恢复新操作留记录 |

## 4. 产品边界与体验规则

每个操作页面都呈现：当前状态、版本/更新时间、允许操作、不允许原因、附件/来源与历史。拒绝时不泄露无权资源名；无权限/不存在可统一 404。失败不清空尚未提交表单。

长任务先返回任务 ID，页面允许离开、重进和查询；“已受理”不显示成“已完成”。离线端允许本地暂存非敏感表单（需显式标识），首发不支持离线审批、离线最终提交或自动合并业务冲突。网络恢复后先读服务器现状。

本系统是经营协作台账，不直接执行支付、不替代会计/法律判断。内部账号是权限主体，不是 HR 档案。博客/SOP 是内部内容，不能因使用 publish 一词就默认上公网。

## 5. 首发范围与验收组织

所有详细需求默认首发必需，明确标记“后续”的除外。微信/抖音无需承担桌面复杂配置和 120 GB 上传；须具备项目查阅、任务处理、文件/知识查阅、合同/报销/采购申请与审批、费用/订阅查阅、服务状态、秘书会话。Android 还须大文件上传与恢复。

“查阅”包含符合权限的详情、历史和附件入口，不承诺所有格式都能在小程序原位预览；不支持时展示受限下载/外部打开说明与可用元数据。跨平台能力降级必须可见并有验收用例。

用户负责确认经营规则与验收人；开发负责实现和技术证据；测试负责独立复现；运维负责资源、发布与恢复证据。实际姓名待指定。范围完成由 [需求追踪矩阵](../quality/02-traceability-and-release.md)判定，不能用页面数量代替。
