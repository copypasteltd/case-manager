# 视觉基础、双主题与设计令牌

版本：v1.0.0-draft；日期：2026-10-23。O=官网实证，D=内部平台扩展；基础色以 [官网取证](01-website-style-audit.md) 为依据。所有数值源保存在 [tokens.json](tokens.json)，Web 使用生成的 [tokens.css](tokens.css)。

## 1. 品牌表达与颜色分工

页面以暖灰白/蓝灰黑为画布，正文以墨色/浅灰白为主体，白色/深蓝灰面板承载内容。蓝色只用于链接、键盘焦点、选中项、来源线和少量图表。一个区域只保留一个视觉最强的主操作；相邻功能不要全部做成实心按钮。

禁止用蓝紫渐变、霓虹描边、通屏品牌蓝、毛玻璃卡片堆叠或彩虹数据卡替代本品牌。登录可以使用很淡的网格/细线，办公页面不得以装饰降低表格对比或占用首屏任务空间。

## 2. 状态色（全部 D）

| 语义 | 浅色前景 / 背景 | 深色前景 / 背景 | 使用范围 |
| --- | --- | --- | --- |
| success | #17633D / #EAF5EE | #8EDDB0 / #163326 | 已完成、检查通过；带明确文字 |
| warning | #8A4B08 / #FFF3DD | #F2C078 / #3B2C16 | 待办、到期、降级、需核实 |
| danger | #B32636 / #FCEDEF | #FFA3AD / #3A1C25 | 失败、异常、业务拒绝 |
| info | #204FC1 / #EBF0FF | #A5BFFF / #1C2C4F | 处理中、当前、可继续 |
| neutral | #5D636D / #EFEFEB | #A0ACC2 / #141A24 | 草稿、归档、未知；未知需文字说明 |

状态必须同时有文字，必要时配不同形状的图标；不能只靠红绿圆点。拒绝是业务结果，接口失败是系统结果，必须使用不同的具体文案。颜色不是状态定义，真实枚举和操作仍以需求/API为准。

禁用控件使用 subtle 背景、disabled 文字并移除激活效果，不用整体 opacity 使必要文字低对比；说明禁用原因或提供旁边可聚焦帮助。只读内容仍使用正常文字色。失权信息不得以灰字形式保留泄露。

## 3. 字体与排版（O 基因、D 尺度）

正文栈沿用官网并补充 Windows 回退：Manrope → Avenir Next → Segoe UI → Noto Sans SC → PingFang SC → Microsoft YaHei → sans-serif。品牌展示栈：Fraunces → Iowan Old Style → Noto Serif SC → Songti SC → serif。代码/版本摘要：SFMono-Regular → Consolas → Liberation Mono → monospace。

衬线字体仅用于工作台/登录的品牌展示标题、知识正文标题等有限场景。操作页标题、表单标签、表格、金额、数字、按钮、菜单和聊天正文统一无衬线；不机械继承官网 h1—h4 全部衬线的样式。未安装品牌字体时允许回退，不从不明 CDN 自动下载；需内置字体时先核对授权并做中英文包体/真机测试。

| 层级 token | 字号/行高/字重 | 使用规则 |
| --- | --- | --- |
| display | 40 / 52 / 600 | 桌面工作台欢迎标题；移动缩至28/40，不用于每个业务页 |
| pageTitle | 28 / 40 / 600 | 主要页面标题，窄屏24/34 |
| sectionTitle | 20 / 30 / 600 | 面板/详情分段标题 |
| subheading | 16 / 24 / 600 | 卡片标题、表单分组、重要字段 |
| body | 14 / 22 / 400 | 桌面正文、表格；长篇阅读可16/26 |
| mobileBody | 16 / 26 / 400 | 小程序/Android主要正文及输入 |
| caption | 12 / 18 / 400 | 时间/版本等辅助信息，不能作为主要表单/审批正文 |
| amount | 24 / 32 / 600 | 汇总金额，常规表格金额仍14/22 |

单位为设计基准 CSS px；工程支持字号缩放，不能禁用浏览器缩放或用固定高度裁切放大后的文字。长中文正文建议行长约36—46个汉字；列表标题允许2行，完整名称在详情/可聚焦展开入口可见，不能只依赖鼠标悬停。

数值使用 tabular-nums；金额右对齐并明确币种，费用比较列统一小数位。币种/汇率/金额精度沿用财务契约，不因界面偏好换算。120 GB、原始字节、预计/实际传输量必须区分，容量展示口径遵循存储协议；不混用 GB/GiB。时间显示业务指定时区及完整时间入口，业务日期与设备时区解耦。示例港币不代表组织默认币种已确认。

首版文案默认中文；简繁及多语言可配置口径仍待业务确认。控件预留至少30%文本增长空间，不将字号压小来塞下翻译。

## 4. 间距、布局与密度（D）

间距采用4px基线：0、4、8、12、16、20、24、32、40、48、64。字段标签至输入8、帮助至输入4—8、字段组之间24、面板内20—24、面板之间24。小屏面板内16、页面左右16；桌面页面32。禁止在同一层级出现17/19/23等随机间距。

| 项目 | 默认值 | 例外/限制 |
| --- | --- | --- |
| 侧栏 / 收起 | 240 / 72 | 收起必须可键盘展开，当前项和名称仍可访问 |
| 顶栏 | 64 | 实色为主，保留面包屑/全局搜索入口 |
| 内容最大宽度 | 1600 | 长篇阅读更窄，避免超宽句子 |
| 抽屉宽度 | 480 | 不超过视口；移动改整页/全屏面板 |
| 紧凑/默认/舒适控件 | 32 / 40 / 44 | 32仅精细指针工具栏；触屏命中区至少44 |
| 移动控件 | 48 | 内容尺寸与点击热区分开验证；平台单位见跨端规范 |
| 表格行紧凑/默认/舒适 | 44 / 52 / 64 | 可选密度持久化；换行时行高可增长 |

密度选项只改变行距/内距，不能通过12px正文获得「紧凑」。移动不使用桌面紧凑模式。无需给3名员工做固定3列；布局必须适应名称、币种、状态和未来人员增长。

## 5. 圆角、描边、层级与阴影

圆角 token：控件10、嵌套区12、面板16、弹窗20、品牌展示框26、胶囊999。主操作按钮胶囊；输入/表格工具按钮10；不要给每个表格单元格加圆角卡片。

描边默认1px，焦点2px+2px外偏移，品牌强调线3px。border.subtle 只做分隔；空白输入、未选复选框等需要边界识别的控件使用 border.control，不能以官网很淡的面板线冒充合格控件边界。

常规数据面板以描边建立层级，不默认叠加厚阴影；shadow.brand 可用于重点摘要，shadow.overlay 用于浮层。浅色浮层阴影为0 12px 28px rgba(12,21,35,.12)，深色0 16px 40px rgba(0,0,0,.42)。遮罩分别为 rgba(14,23,38,.48) / rgba(0,0,0,.64)，遮罩后正文不参与活动界面的可读操作。

zIndex：基础0、吸顶10、导航20、下拉100、抽屉200、弹窗300、toast400、tooltip450。弹窗内下拉必须挂载至同一浮层根并满足正确层级，不能机械按100被弹窗盖住。深色通过表面/描边区分浮层，不能只依赖黑阴影。

## 6. Logo、图标与图像

沿用 [当前 PNG 标识](assets/official-logo-light.png) 和 [深色配对](assets/official-logo-dark.png)。侧栏展示32—40px，登录48—56px，最小建议24px；外部至少留标识宽度的1/4净空（D，待品牌审定）。不得拉伸、裁切、改变图形色、加渐变、旋转或单独拼接字母。侧栏收起保留有可访问名称的标识，点击回工作台。

产品功能图标统一一套24网格、1.75—2px描边、圆端点的线性 SVG；常规16/20/24px。只为意义而用图标，不用 emoji 充当导航。图标按钮有可访问名称；装饰图标对读屏隐藏。文件格式可用文字缩写加轮廓图标，不能因文件扩展名而覆盖安全/扫描状态。

不在工作台使用无业务价值的图库大图。头像缺失用首字/缩写与中性背景；项目封面可选且不挤占任务区。秘书来源引用以3px蓝线、文件名/版本/更新时间呈现，表达可追溯性。

## 7. 动效与反馈

时长 token：快速120ms（颜色/焦点）、普通180ms（菜单/提示）、慢速240ms（抽屉）。缓动 cubic-bezier(0.2,0,0,1)。办公表格不做 hover 上浮，重要信息不等滚动 reveal 才显示。过渡只使用 opacity/transform，避免高度持续动画引起阅读跳动。

尊重 prefers-reduced-motion 及平台减少动态效果：去掉位移/循环装饰，状态直接切换；必要进度仍用文字与静态进度条。加载骨架不能无限闪烁且不替代超时错误。秘书流式内容按消息容器稳定增长，用户往上读时不得强制滚到底。

## 8. 无障碍与对比度

基线目标为 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)。普通正文至少4.5:1，必要控件/图形边界至少3:1；项目对关键状态文字也统一按4.5:1执行。WCAG AA的指针目标最低要求为24×24 CSS px（有例外），本项目采用更大的 Web 触屏44、移动48设计命中区；不能把项目尺寸写成WCAG AA原文要求。

| 已核算组合 | 约对比度 | 用途 |
| --- | --- | --- |
| 浅色默认正文 / 画布 | 16.60:1 | 正文 |
| 浅色次级正文 / 画布 | 5.59:1 | 辅助信息 |
| 浅色蓝色 / 白面板 | 5.12:1 | 普通链接 |
| 浅色选中文字 / 选中底 | 6.25:1 | 导航/选择 |
| 深色蓝色 / 面板 | 6.77:1 | 链接/焦点 |
| 浅色控件边 / 白面板 | 3.72:1 | 输入边界 |
| 深色控件边 / 面板 | 3.87:1 | 输入边界 |

实际完整检查见 [对比度报告](evidence/contrast-report.json)。报告只验证列出的实色组合，不自动证明图片、透明叠加、第三方控件、整张页面和实际产品合规。开发新增组合时必须重新检查，不从「色板通过」推导「任意配对通过」。

必须有可见键盘焦点、逻辑阅读顺序、跳至主内容、输入标签、错误关联和模态焦点管理。金额/图表具备文字等价信息；字号200%和窄屏重排不丢失动作。tooltip 不能承载唯一必要说明，toast 不能作为失败的唯一长期记录。

## 9. 图表与数据呈现（D）

序列1—6浅色：#1F5EFF、#202D45、#0F766E、#6B4AC3、#9A6700、#5D636D；深色：#79A2FF、#B5C1D8、#6ED9C4、#C4A6F2、#F2C078、#A0ACC2。紫色仅是多序列区分色，不扩展成品牌主色。

同图最多建议6条主要序列，增加时用筛选/分图。必须配文字图例、线型/形状、值与时间口径，重要数据提供表格。不能把「预测、已发生、现金支付」三个口径叠成含义不清的一个总数。无数据与零值区分；坐标轴、缺失区间、刷新时间、币种和汇率条件可见。图表颜色组合未在正文对比表中全部验证；后续对实际线宽、相邻序列及图形背景单独做图表可辨识检查。
