# 移动端项目协作与交付验收设计

日期：2026-10-24。适用：Taro微信、抖音公共页面及后续Android原生适配。采用[官网风格总规范](00-style-design-specification.md)及现有语义令牌；实现与验证范围见[移动项目协议](../development/45-mobile-project-collaboration.md)。

## 1. 页面分层

项目概况保留名称、阶段、范围和业务日期，资料入口采用连续列表：任务、里程碑、风险、问题、成员、交付、文件及记录。窄屏不把这些入口压成多列小按钮。进入资料后先标出项目上下文，再显示本组资料、搜索和分页。

里程碑／风险／问题详情依次显示当前阶段、负责人、截止时间、说明及专有字段。风险的概率和严重程度使用明确文字；“已发生”可进入对应问题。成员使用当前姓名及项目角色，不能仅显示UUID。业务日期保持原日期，事件时刻明确香港时区。

任务将说明与责任／前置条件分组，先读当前事实，再处理任务，再进入讨论。前置任务可进入准确详情；评论显示作者、时刻、修订和正文，修订历史紧邻相应评论。发布、保存修订和任务状态变化各自使用明确动作名称。

## 2. 交付列表与编辑

交付列表使用名称、准确阶段、更新时间及“固定文件版本与人工验收”的短说明。旧协议记录标出“来源待核实”。新建入口仅在当前项目及权限允许时出现；无写权限保留有权阅读内容。

编辑采用完整单列页面：名称、验收准则、交付负责人、可选里程碑、保存原因。名称与长准则允许换行和内容增长，选择器有持续标签。已选里程碑不在当前分页时单独读取准确条目；不能把“候选未加载”显示成“未关联”，也不能静默清除关联。

页面沿用暖灰白／蓝灰黑画布、中性色面板、黑白主按钮和少量蓝色强调。主表单采用单个最强动作；返回、刷新、分页和查阅固定版本保持次级样式。

## 3. 提交固定文件

提交区先说明将固定哪些内容，再提供项目／公共文件范围、名称搜索、文件与版本分页。每个版本同时标出原名、序号、当前／历史、大小、扫描和可用性；SHA-256完整可换行，不能截断成无法核对的装饰码。

选择动作明确写为“选择固定版本N”；已选集合独立显示版本及移除入口。不可用或扫描未通过的候选保留准确说明并禁用选择；不能用绿色勾号表示文件内容已被人工阅读。不同文件的版本独立选择，不默认为全部最新版本。

提交说明与原因紧邻确认按钮。页面隐藏再返回时保留匹配当前版本的文字，清空文件选择，并显示需要重新选择的提示。确认按钮只有在1—20个版本及必填文字齐备后可用。

## 4. 验收与历史

当前资料与“第N次提交·本次固定依据”分组。固定区域使用提交时名称、准则、说明、文件和内容摘要；不能从当前草稿借字段补全旧修订。

验收初始动作为“退回补充”。选择“通过验收”后显示两个独立、默认未勾选的声明：实际核实全部准确文件、逐项核实固定准则。声明文字持续可读，触控区域至少44 CSS px。提交人看到不能自验的说明，不能通过勾选绕过独立验收。

说明与真实两步验证独立于核实声明。验证码不用作普通草稿；验证成功只解锁当前确认动作，不自动执行。返回页面、刷新当前对象或切换修订后，声明与前端验证均重新开始。

历史页写“历史固定依据”“当时已验收／当时已退回”，并说明不代表当前修订已通过。顶部当前头的徽标必须带“当前交付阶段：”限定；不能让当前已验收徽标冒充旧修订的验收结果。旧修订不出现针对当前头的编辑或验收按钮；新提交后旧验收仍可查阅。

## 5. 失败与恢复

读取失败与空列表分开，权限未知时不呈现写表单。只读角色不显示新建、编辑、提交及验收入口；项目结项中／已归档／已取消保持只读。

409／412保留本次文字和针对旧依据的上下文，停止重复提交，给出刷新核对入口。结果未确认不能显示成功；提示先查阅列表和对象核对，不能暗示重新创建一定安全。刷新后以最新事实重新组织动作。

任务与交付草稿提示统一写明恢复的是会话内文字，文件、核实和验证码需要重新操作。不依赖短暂toast承载失败或版本冲突。

切页不生成另一次业务动作。同一会话、权限及业务依据下，尚未核对的精确请求保留原幂等键；只有用户再次明确操作时才向服务器核对，不能由返回页面自动发送。结果未知且用户改变原输入时，阻止替换请求并要求先核对结果。此保护仅驻留内存，不承诺整页重载后的恢复。

## 6. 设计验收范围

本轮审阅检查浅／深主题及320、390、768 CSS px：长交付名称、摘要换行、字段可读、按钮命中区、评论、风险及交付列表／编辑／提交／验收／历史。使用实际Taro H5公共页面与隔离API，截图和清理结果归入[本轮记录](../quality/evidence/mobile-projects/result.json)。

微信／抖音的原生选择器、文件内容、输入法、安全区、读屏及系统大字仍需各平台真机检查；Android还需要实际原生宿主和对应适配。H5截图与两小程序编译不代表这些门禁通过。所有自建浏览器上下文和标签页在检查结束关闭，不启动本地虚拟化环境。
