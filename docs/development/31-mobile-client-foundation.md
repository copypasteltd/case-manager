# Taro 移动客户端与会话约束

日期：2026-10-23。本文记录 `app/mobile/` 的实际公共客户端底座及验证边界；首发仍要求微信、抖音、Android 同批达到各自能力，不因先实现公共页面而缩减[四端矩阵](06-clients-and-pages.md)。

## 1. 工程与构建

公共客户端使用固定 Taro 4.3.1、React 18.3.1、TypeScript 5.9.3 和 webpack 5.91.0。依赖随根工作空间锁文件安装，不能依赖另一台电脑恰好存在的全局 Taro/Babel。React Babel preset 属于必须显式安装的可选 peer；本仓库固定 7.28.5。

`src/platform/session.ts` 只依赖传输接口和生成契约，负责登录、MFA、续期及命令请求；`platform/taro.ts` 将其连接到 Taro.request。每个平台的设备类型必须真实声明，微信为 wechat、抖音为 douyin，Android 为 android；当前 H5 仅在本地用 wechat 身份检查公共页面，不构成另一个发布端。

当前 device_type 是客户端声明并被服务端记录的渠道，不是微信/抖音平台凭证或设备完整性证明。真实平台身份绑定和设备验证仍待实现，不能把 H5 检查中的渠道值解释为已核验的原生平台身份。

构建必须显式提供 `CP_MOBILE_API_ORIGIN`，只接受无凭据、无路径、无查询及片段的 HTTPS origin。显式 `CP_MOBILE_BUILD_PROFILE=local` 才允许 localhost/127.0.0.1 的 HTTP。代码不猜测生产域名。H5 目标额外要求 local profile，不能以它替代小程序包或 Android 原生应用。

在 app/ 原生终端执行 `npm run build:weapp`、`npm run build:tt`，输出分别位于 mobile/dist/weapp、mobile/dist/tt。真实平台 AppID、合法请求/下载域名、隐私声明、平台权限与开发者工具导入配置仍需分别接入和实测；仅编译成功不等于开发者工具/真机/提审成功。

`python scripts/verify_mobile.py` 依次执行会话测试、类型检查和两个小程序编译。脚本使用明确的本机演示 API origin，不访问 API 或云，不启动模拟器。脱敏结果保存到[编译与会话证据](../quality/evidence/mobile-foundation/result.json)，完整构建日志仅保存在忽略目录。

## 2. 登录与敏感资料

账户激活、登录、MFA 设置、验证码与恢复码复用后端真实契约：login/password/device_type；challenge/code。设置接口只返回设置密钥，不要求服务再次回传 challenge。恢复码首次出现必须经过保存确认才能进入工作空间。

access token、refresh token、challenge、设置密钥、密码及恢复码只放在内存，不写普通平台存储、URL、日志或证据。页面隐藏清除密码和验证码；登录页卸载时清除未完成登录，完成导航后保留内存会话。进程重建或完整页面重载后重新登录。只有外观偏好允许写普通存储。

后续若增加持久登录，必须单独实现平台安全存储、设备丢失撤销与密钥生命周期；不能为了减少登录次数把 refresh token 放进通用 setStorageSync。现有底座不宣称小程序提供与 Android Keystore 相同的保护。

退出先清除本机内存，再请求服务器撤销。网络失败时明确区分“已退出本机”和“服务器撤销尚未确认”。页面重新显示时重新读取 /me 和业务资料，不恢复旧查询缓存充当当前授权证明。

任务与审批尚未提交的原因、所选动作可在本进程内保留15分钟，最多32项、合计100000个字符，单项原因上限20000；任务输入仍受200字符字段限制。不写普通存储。恢复必须匹配登录代次、本人、最新服务端授权版本、对象版本；审批另匹配申请修订/摘要和步骤版本。授权版本前进时清空旧输入，旧页面不能将其降回；退出和新登录立即清空。返回页面先重新取得权限与资料，再恢复准确匹配的输入并提示重新核对；不恢复验证码、MFA通过状态、服务器结果或自动提交。提交成功清除本次输入。过期或被有界淘汰的草稿不保证恢复，完整重载后不保留。

## 3. 并发、取消与命令

同一会话的续期使用单个共享请求，避免轮转 refresh token 时互相撤销。每次新登录/退出递增本机会话代次；迟到的旧登录、续期或业务读取不能覆盖新身份，旧续期失败不能清除新登录。

读取页面持有 Scope，隐藏、重读和卸载关闭旧 Scope 并中止对应 Taro 请求；已经到达的迟到结果也必须丢弃。后台续期属于当前会话，不被某一页的取消错误地当作已回滚。只有 GET 遇到 401 可续期并最多重试一次；命令不自动重放。

每项新命令使用独立意图键，来自服务器公开随机 request nonce、真实渠道和递增计数器，不把 access/refresh token 或其片段拼入键。相同表单体沿用同一键；更改意图必须换键。授权仍由服务器在每次命令和幂等回放前核对。

任务与审批动作固定打开时的资源版本。审批额外固定步骤版本、申请版本、修订 ID 和内容摘要。网络中断、无效成功响应、409/412 或会话切换后停止该表单继续提交，保留原因，要求刷新核对。客户端取消不代表服务器回滚，也不能把未经确认的写入显示成已成功。

审批 MFA 使用实际 step-up 接口，不由前端布尔值代替。页面中的短时提示只负责交互，后端仍检查当前会话和实际验证时间。金额及收付计划保留服务器十进制字符串，不转成 JavaScript 浮点数重新计算批准依据。

## 4. 公共界面

已接入源码的页面包括：内部账户激活/登录/MFA、工作台、项目与任务列表/详情、目录与文件版本、知识正文、业务申请固定快照/审批顺序、本人审批动作、会话成员及外观/退出。列表按真实 cursor 继续读取，不能把第一页当作全部。无授权内容由服务器过滤，错误后不展示旧成功数据。

任务动作包括开始、受阻/恢复、送审/退回/完成、取消及按权限重开；后端继续检查项目阶段、任务版本和前置依赖。按钮权限只是呈现条件。知识正文作为普通文字显示，不执行其中 HTML、脚本或“指令”。文件显示正式版本、摘要、扫描状态及实际副本状态，不能把复制中写成已备份。

审批详情显示固定修订中的收付方向、类型、类别、分类、项目、负责人、金额/其中税额、往来方、日期、条款、备注、正文版本、收付计划及其他附件。可取得的人员姓名按当前可见资料显示，责任身份仍由固定修订确定；尚无可见姓名时明确显示已指定，不编造姓名。扫描例外保留风险提示，批准、签署、生效和实际收付款分别表达。正文与附件的资料入口携带准确版本，使用 `GET /files/{id}/versions/{version}`，失败时不改读当前版本；版本不在历史第一页也能准确读取。未知原文件名显示未提供，不以现在的文件名冒充历史名称。这里尚未接通原件预览/下载。

目前仍需补齐的公共业务包括任务评论/依赖、里程碑/风险/交付、知识基础编辑、固定文件预览/下载及普通附件、完整 OA 申请草稿/提交、费用订阅、秘书运行/计划和服务状态。Android 120GB 原生传输另行实现。以上不是首发范围删减，也不能由空页面或演示数据冒充完成。

视觉沿用[官网风格体系](../design/README.md)。scripts/sync_design.py 从 docs/design/tokens.json 生成两个主题各39个语义变量并复制官方 Logo；不维护第二套独立色板。使用750设计宽度，按钮触摸区保持至少44设备逻辑像素，表单和列表为触屏布局；颜色之外仍显示中文状态。支持外观偏好，平台没有主题事件时保留手动选择。字体使用系统回退，不在办公流程中加载外部字体服务。

页面根节点显式继承令牌中的字体栈，输入控件也必须继承，避免 H5 宿主默认为其他字体。品牌行不拆分 Logo/字标，右侧操作使用内容宽度。Taro 的 H5 样式转换会改写原生标签选择器，文本框内部因此使用组件类名约束字体、透明背景、前景色和尺寸，不能只在宿主写颜色就认定深色输入可读。共享包装组件分别映射 H5 和小程序的操作名称、按钮角色及禁用语义；H5 检查另覆盖键盘触发。原生读屏仍需真机验证。

H5 自定义元素可能保留 `disabled="false"` 属性。禁用样式由包装组件按布尔状态生成的类名决定，不能以 `[disabled]` 是否存在判断；可用操作不得套用禁用透明度。44逻辑像素的下限使用不随750设计稿缩放的单位，不能把44设计像素当作实际触摸尺寸。

## 6. Android 兼容放行点

2026-10-23 核对的 [Taro RN 4.3.1 包元数据](https://registry.npmjs.org/@tarojs/taro-rn/4.3.1)要求 React ^18、React Native ^0.73.1、Expo ~50；rn-runner 有相同 RN 范围。只读包元数据保存在[兼容查询记录](../quality/evidence/android-compatibility/packages.json)，不代表已安装或成功运行。[React Native 官方版本目录](https://reactnative.dev/versions)将0.73列为已归档、不再维护的版本。这个兼容范围是当前依赖约束，不能据此写“已支持当前受维护 RN”。

Android 需要独立原生宿主、受控凭据适配、SAF/持久 URI 授权、后台有界读取、断点状态、系统取消/重启恢复及120GB真机证据。禁止使用 WebView 的 Blob/整文件缓存冒充原生续传。不能只改 peer 版本声明就声称完成 RN 升级。

当前两个小程序编译、公共会话测试及 H5 检查均不构成 Android 已完成证据。后续先独立验证 Taro RN 与受维护宿主的兼容路径，并记录补丁、可重复构建和设备验证；遗留版本实验不得绕过发布门禁。全过程继续遵守禁止本地 Docker/WSL/虚拟化环境的约束。
