# 增量72：秘书创建里程碑与任务关联

本增量补齐项目秘书的实际写入能力。员工在项目会话中完整选择里程碑标题、项目成员负责人、带时区的目标时刻和原因，核对后随消息发送。Go 控制器调用原 `CreateMilestone` 业务命令，返回新里程碑及真实业务回执；任务关联由另一个明确请求完成。代码在 `app/`，本文与验证记录均在 `docs/`。

## 1. 行为与边界

| 编号 | 行为 | 实现约束 |
| --- | --- | --- |
| MC-01 | 选择创建范围 | 只能在对应项目会话中选择当前项目；`id` 是父项目 ID，`expected_version` 是人工选择时的项目版本 |
| MC-02 | 填写完整内容 | 必须同时固定 `title`、`owner_id`、`due_at`、`reason`；不接受缺项、显式空值、任意新建 ID 或额外状态字段 |
| MC-03 | 明确发起授权 | 表单预览本身不创建业务；通过已认证员工的正式发送固定不可变授权，普通聊天与历史引用不提供写权限 |
| MC-04 | 执行原业务 | 原项目写入阶段、有效项目成员、分类、AI、当前受众和权限继续生效；不直接插业务表绕过原命令 |
| MC-05 | 区分父子版本 | 新 ID 由原业务分配，新里程碑版本从 1 开始；父项目基础版本不等于新里程碑版本，不显示虚假的父项目版本递增 |
| MC-06 | 重试不重复创建 | 同一工具调用重放返回已保存回执；同一授权使用新调用键仍复用原操作，不创建第二个里程碑 |
| MC-07 | 保留真实证据 | 新里程碑、原幂等操作、审计、事件、不可变提交和工具回执在同一事务中提交；结果引用新里程碑 ID |
| MC-08 | 单独关联任务 | Web／Taro 从同项目真实分页列表选择里程碑；用既有 `update_task` 固定任务版本与 `milestone_id`，创建不会自动关联任务 |
| MC-09 | 明确解除关联 | 必须显式选择清空并发送 `milestone_id:null`；跨项目、已达成或已取消目标继续由原业务拒绝 |
| MC-10 | 中断与冲突 | 原登录撤回、取消、父项目版本变化、只读阶段及权限变化阻止后续执行；不自行刷新版本扩大原授权 |

## 2. 接口与事务

新增受控工具 `create_milestone`，复用现有运行创建接口的 `mutation`。没有新增公开业务端点，也不开放 SQL、文件路径、任意 HTTP 或模型自行批准能力。

```json
{
  "tool": "create_milestone",
  "arguments": {
    "id": "父项目的小写 UUID",
    "expected_version": 7,
    "title": "首轮交付审阅",
    "owner_id": "有效项目成员的小写 UUID",
    "due_at": "2027-03-05T18:00:00+08:00",
    "reason": "将已核对的交付安排登记为里程碑"
  }
}
```

准备阶段固定父项目当前投影、版本、会话修订、受众、登录与授权摘要。执行前复核原登录和父项目；创建后验证新里程碑确属该项目、版本为 1、状态为 open，并核对全体当前受众对新结果的阅读权限。后续工具及完成再次核对实际新里程碑版本与摘要。历史授权仍按原受众和当前权限查阅，不改写为当前业务资料。

迁移 [0066](../../app/backend/migrations/0066_agent_milestone_creation.sql) 扩展工具白名单及准确创建约束。原更新仍要求基础版本加一；仅创建分支允许结果版本为 1，并额外核对原幂等操作、真实新记录、原项目版本、创建人及全部创建字段。原不可变、原登录及延迟回执约束保留。

## 4. 验证及交付限制

[原生集成测试](../../app/backend/internal/httpapi/agent_milestone_creation_integration_test.go) 包含十项场景，覆盖完整输入、实际创建、真实事务证据、两种重复调用、关联／解除、跨项目／关闭目标、无效负责人、父项目冲突、只读阶段、取消、不可变历史及原登录撤回。Web 测试另核对创建结果不能以父项目、错误负责人、错误日期或错误版本冒充。

实际执行结果、失败尝试、当前来源摘要和资源回收记录见[验证记录](../quality/evidence/milestone-creation/verification.md)。浏览器使用隔离数据库和真实登录／API，运行时使用受控本地执行器；不把页面发送等同于真实模型执行。新 Android 开发 APK 与两个小程序编译也不能代替平台、真机或正式发布验收。
