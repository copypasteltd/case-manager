本轮范围是 Web 任务视图。完整项目聚合、跨OA／财务旅程、多端操作补齐、真实资源及首发验收仍按原差异表推进。里程碑管理沿用既有独立页签；未增加高级甘特拖拽、资源优化或自动排期。

## 2. 来源、分页与操作

列表、看板及时间线使用同一 `GET /v1/projects/{id}/tasks` 查询，传入 `state`、`q` 和签名游标。筛选交给后端；不在第一页上执行本地筛选并误称查询完整。切换视图不会更换权限或生成另一套任务事实。

编辑可能令同一任务在游标分页中再次出现；按稳定ID去重，保留实际观察到的最高记录版本。去重不等于全项目一致快照，页面始终保留“已加载”措辞；刷新实际重新读取当前查询。后续页仍需人工加载，不自动递归拉取全部项目数据。

当前读取出错时不把缓存内容继续展示成有效结果，提供重新读取入口。筛选为空与读取失败分开显示；403／404等实际撤权结果同样隐藏任务列表、看板及时间线。项目名称和其他既有页面信息沿用原查询生命周期，本轮不声称能抹除员工先前已获授权读取的客户端资料。

没有新建写入协议。卡片及时间线标题打开既有任务详情；编辑、分配、依赖管理、状态变化继续调用原接口，使用实际版本与权限。看板分列不能绕过验收或依赖约束，日期也不因任务状态变化自动修改。

## 3. 日期语义

时间轴按实际毫秒时间戳计算位置，文字统一香港时区，包含日期、小时与分钟。时区偏移不同但对应同一时刻的输入具有同一位置。未设置的开始／截止保持未知，不用项目开始、当前时间或完成时间补齐。

| 情况 | 图形／事实 |
| --- | --- |
| 两端有效且截止晚于开始 | 比例区间 |
| 两端相同 | 时间点 |
| 仅开始日期 | 点，明确仅开始 |
| 仅截止日期 | 点，明确仅截止 |
| 两端未设置 | 未排期列表 |
| 不可解析或截止早于开始 | 日期待核对列表，不进入图轴 |

图轴由当前加载的有效日期范围派生，并加显示边距。图轴边界仅用于绘图，不表示项目日期已被修改。长期项目仍为每任务一条比例轨道，不按日生成无界网格；窄屏在内部区域横向滚动，不扩宽整个页面。

展开前置任务时重新读取原授权接口；加载／错误不显示旧依赖为当前事实，可重试。每次只展开一项，避免为所有任务发起依赖请求；标题可以进入原前置任务详情。前置状态与能否操作仍以服务端实际命令时检查为准。
