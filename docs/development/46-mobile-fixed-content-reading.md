# 移动端固定版本内容读取协议

日期：2026-10-24。对应 FILE-03/05、TC-MULTI-06。沿用[下载授权协议](17-download-authorization-and-streaming.md)、[四端能力矩阵](06-clients-and-pages.md)、[官网风格总规范](../design/00-style-design-specification.md)及[阅读页设计](../design/19-mobile-fixed-content-reading.md)。本地实现与设备验收分别记录；本文不改变四端首发和 Web／Android 120 GB 的要求。

## 1. 问题与本轮范围

原移动页面可以核对版本、扫描与副本元信息，但不能阅读附件内容。审批、合同正文和项目交付引用均已固定版本，员工仍需实际打开相应内容，才能完成人工核实。

新增第八个公共页面 `pages/content/index`。从准确的版本入口进入，先读取文件及该版本，主动申请授权，再顺序读取、验证和展示。仅在完整摘要通过后提供内容；读取完成不写入“已阅读”、审批声明或验收声明。

本轮提供有界文本／图片阅读和 PDF／Office 本机查看器适配代码。微信／抖音真机文件系统、查看器、平台审核，以及 Android 独立宿主和大文件原生传输仍有独立验收门槛。H5 是本地公共页面检查入口，不作为新增的生产移动 Web 客户端。

## 2. 传输选择

微信、抖音会话创建下载授权时，一律选择 `authenticated_proxy`。Web／Android 普通文件继续使用既有固定源签名读，机密文件继续使用受控代理。使用服务端已验证的会话渠道，不能由客户端任意指定其他渠道。

小程序公共读取采用不超过 1 MiB 解码字节的 JSON 分段响应。这样无需依赖各端对二进制响应头、重定向和云端条件头的一致实现；应用 Bearer 只发送到配置的 API 域名。JSON 中的 base64 增加约三分之一传输量，仅用于有界附件阅读；不能据此把 120 GB 文件改为后端 JSON 中转。

返回授权中的 URL 不被移动阅读器消费。阅读器只将经过 UUID 校验的授权 ID 组成固定的相对 API 路径。URL、授权响应和内容不进入普通本地存储、草稿、日志或剪贴板。

## 3. API 契约

沿用 `POST /v1/file-versions/{id}/download`，请求 `disposition=attachment`，显式幂等键。不自动重发 POST；授权失败／结果未确认时不显示内容。授权的文件版本、SHA-256、大小、扫描结果、读取方式和有效期必须与已显示版本一致。

新增 `GET /v1/downloads/{id}/chunks?offset=0&length=1048576`，必填 `If-Range: "<该版本 SHA-256>"`。成功为 HTTP 200 的 `DownloadChunkResponse`：

| 字段 | 约束 |
| --- | --- |
| download_id、file_version_id | 对应本次授权和准确版本 |
| offset、length、total_size_bytes | 规范十进制字符串；精确匹配请求与固定总大小 |
| sha256 | 正式版本的完整摘要 |
| chunk_sha256 | 服务端实际读取本段字节的 SHA-256 |
| data_base64 | 规范 base64；解码长度精确匹配 length，最多 1 MiB |

起点和长度各出现一次；禁止额外查询字段、外部 URL、客户端 Range 头、负数、前导零、溢出及超范围读取。长度为零仅允许空文件且起点为零；这不表示当前上传流程已经支持所有空文件情形。非规范参数返回 400／416；缺条件头为 428，不一致为 412；失效授权、失去权限或过期沿用原下载规则。所有状态以[生成契约](openapi.json)为准。

## 4. 服务端读取与审计

两种受控读取共用授权解析、文件权限、会话家族、渠道、分类、祖先目录可用性、版本及已校验副本选择。延续进程最多 3 路、每用户 1 路、每路 2 MiB/s、64 KiB 读缓冲及每 2 秒权限复核。

JSON 路径只缓冲当前不超过 1 MiB 的段，验证固定源 ETag／OSS Version ID、声明长度及准确 EOF。完整段读取后、发送 JSON 前再次复核当前权限。任何中途截断、源不一致或复核失败都返回错误信封，不输出已有局部 base64。

成功响应设 `private, no-store`，不返回云 URL、对象 Key 或应用凭证。读取结果审计的 bytes_written 是解码字节：只有完整 JSON 信封写出后，才能记录完整范围；仅进入私有缓冲不算送达。HTTP 写入成功不代表客户端已收到、已核对完整文件或员工已阅读。原二进制路径仍在响应开始后以中断结束，不向文件流追加 JSON。

未新增数据库表或改写已应用迁移；现有授权表允许普通文件选择受控代理。下载授权不可变规则继续生效。

## 5. 客户端完整性与取消

阅读器固定一个版本，不跟随 current_version，不在失败或到期后换成最新版本。按段检查身份、规范 base64、实际长度与本段摘要，再写入暂存；顺序更新完整 SHA-256。最后摘要匹配才能生成可展示对象。格式声明与文件头不符时停止，不能将 HTML／SVG 当图片或文档执行。

使用固定 `@noble/hashes 2.4.0` 的增量 SHA-256，锁文件纳入来源摘要；测试以 Node 标准库作为独立摘要参照。未自行实现密码学算法。规范 base64 和严格 UTF-8 解码是跨端纯逻辑；文本按原文显示，不解析 HTML、脚本或 Markdown 链接。

每次读取使用独立 Scope，归属于页面 Scope。取消、隐藏、退出或换会话中止请求，丢弃迟到结果并清理暂存。GET 沿用内存会话的单次刷新规则；正常刷新不扩大权限。页面返回后必须主动重新读取；授权到期显示明确提示，不后台创建新授权。

## 6. 格式和资源预算

以下是当前实现的工程预算，不是平台官方文件上限，也不是最终首发能力缩减。

| 类型 | 当前预算与处理 | 不满足条件时 |
| --- | --- | --- |
| UTF-8 txt／Markdown／CSV／JSON | 最多 1 MiB，严格解码，纯文本展示 | 提示编码／大小问题，转 Web 原件下载 |
| PNG／JPEG／GIF／WebP | 最多 32 MiB，文件头核对后由图片组件显示 | 显示格式或渲染错误；不执行 SVG |
| PDF | 最多 32 MiB，文件头核对；原生端调用本机查看器 | 无法打开时提供 Web 原件下载说明 |
| doc／docx／xls／xlsx／ppt／pptx | 最多 32 MiB，扩展名与 MIME 对应、容器文件头核对后调用本机查看器 | 不承诺所有系统版本均支持；其他格式不强制打开 |
| 扫描豁免文件 | 保留准确豁免提示，不在本页预览 | Web 受控下载并核对风险 |
| 更大文件、未支持格式 | 不发预览授权、不尝试整文件载入内存 | 保留准确元信息及 Web 下载路径说明 |

文本和 H5 预览使用有界内存；H5 对象 URL 在隐藏／清除时撤销。原生图片及文档以 1 MiB 段追加到应用拥有的暂存文件，不能使用原文件名拼接路径。临时名由固定版本 UUID、时刻和进程序号构成；不同读取不复用路径，避免取消旧任务时误删新任务文件。

原生启动时仅清理精确匹配自有命名规则的遗留暂存；清理失败不继续创建新的原生文件。正常取消／隐藏触发清理，失败给出重启提示。调用文档查看器期间持有短期文件租约，待调用完成再清理，防止打开过程中先删除文件。系统查看器／操作系统可能保留自己的副本，不能承诺远程收回、物理擦除或立即删除全部系统缓存。

## 7. 实现位置与验证

后端：`app/backend/internal/httpapi/downloads.go`、`internal/files/downloads.go`。移动端：`app/mobile/src/platform/content.ts`、`content-sink.ts`、`pages/content/`。契约源：`app/scripts/build_openapi.py`；生成后端嵌入契约及公共 TypeScript 类型。

| 层次 | 核查重点 |
| --- | --- |
| 纯逻辑 | 双段、空文本、完整／单段摘要、固定身份、非规范 base64、UTF-8、伪装格式、取消、到期、写入失败与预算 |
| 原生 API／PG | 两渠道代理、无云签名、会话／成员撤销、范围边界、缓冲期撤权、截断不泄露局部内容、源关闭与审计 |
| 受控真实字节 | 实际上传冻结、摘要、扫描、迁移到正式对象、提交及分段读回；目标保留实际 WritePart 字节 |
| 本地真实 UI | 历史与当前版本分开、文本原样、真实 PNG 解码、双段 PDF 摘要、降级、清除／隐藏、取消与撤权 |
| 编译 | TypeScript、微信和抖音各自编译产物 |
| 尚须实测 | 两小程序真机文件系统／打开／清理、抖音 Android 限制、Android 宿主、120 GB、香港跨境网络和真实双云 |

执行入口：`python app/scripts/run_mobile_browser.py --content`；拥有自己的本地测试数据库、H5 审阅端口、原生 Edge 进程及上下文，finally 释放。源码在夹具启动／构建及浏览器核查前后均冻结核对。证据放入[移动内容证据目录](../quality/evidence/mobile-content/)，失败尝试保留，不能用通过记录覆盖解释失败原因。

## 8. 外部依据与边界

[Taro request 文档](https://docs.taro.zone/docs/apis/network/request/)及[文件系统说明](https://docs.taro.zone/docs/apis/files/FileSystemManager)用于适配研究；公共 JSON 通道不依赖未验证的原生响应头行为。Taro 4.3.1 的编译能力不能替代设备能力。

[抖音 openDocument 官方说明](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/file/tt-open-document)列出支持格式并明确 Android 的小程序内预览限制；因此文档打开失败必须有准确降级，且列为真机验收事项。[noble-hashes 官方仓库](https://github.com/paulmillr/noble-hashes)说明增量摘要 API；精确版本由本仓库锁文件固定。
