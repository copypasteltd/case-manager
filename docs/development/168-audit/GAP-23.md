No fresh-request bypass is claimed: `httpapi/server.go:193–230,276–293` calls `Authenticate`, and `identity/service.go:277–297` rejects an already-revoked token. Independent review must judge the requirement's applicability to this captured/in-flight boundary; no runtime reproduction is claimed.
